# A.E.O.N. Archive Terminal

Welcome to the A.E.O.N. (Archive of Extinct Orbital Networks) Terminal. This is an interactive, narrative-driven 3D web interface built with React, Vite, Tailwind CSS, and TypeScript. 

## Features
- Immersive 3D narrative interface
- High-performance local GLTF/GLB 3D models with animations
- Dynamic splash cursor and visually striking aesthetic
- Multi-planet interactive solar system with bloom effects

## Setup

```bash
npm install
npm run dev
```
